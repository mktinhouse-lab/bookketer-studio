# 책 30초 요약 지침

> 기준 게시물: https://www.instagram.com/p/DebTFiHnwsf/ (트렌드 코리아 2027 키워드 요약)
> 이 파일은 기획 AI가 매번 읽습니다. 잘 된 게시물에서 배운 걸 계속 덧붙여 주세요.

## 구성
1. **표지**: 책을 든 인물 사진 + 왼쪽 위 흰 라벨 2개(북케터 밈 / 30초 요약) + 아래 헤드라인 2줄
   - `30초 요약` / `[[책 제목]]` (책 제목은 연두)
2. **목차 장**: 연두 태그 "30초 요약" → 큰 책 제목 → 작은 부제(슬로건·원제·한 줄 정의)
   → 키워드 목록 `01 권태사회` … → 연두 안내 "키워드 뜻 빠른 요약 보기! →"
3. **키워드 장(한 장에 2개, 위·아래 반씩)**: 연두 태그 `KEYWORD 01` → 큰 키워드 → 작은 영문 부제
   → 설명 2줄 (1줄 흰색: 현상·문제, 2줄 연두: 한 줄 정의·결론)
   - 각 줄 22자 안팎. 키워드마다 어울리는 사진 검색어(image_query)를 준다.
4. **셀프체크 장**: 연두 태그 "SELF CHECK" → "나는 몇 개 해당?" → 작은 부제 → ☐ 체크 문항 6~8개(일상 행동으로)
   → 연두 안내 "내 개수를 댓글로 남겨주세요!"
5. **팔로우 장**: "저장해두고 꺼내보세요!" / "트렌드·책 소식, 북케터밈에서 빠르게!"

## 요약 유형
- **키워드 요약**(트렌드·개념서): 책이 제시한 키워드를 그대로 쓰고, 영문 부제는 원서 표기.
- **자기계발 핵심 요약**: 책의 핵심 원칙·습관·개념을 키워드처럼 뽑는다.
  설명 1줄은 "왜 안 되는지(문제)", 2줄은 "책이 말하는 해법"으로. 영문 부제는 짧은 영어 표현.
  셀프체크는 "나는 몇 개 실천 중?"으로 바꿔도 좋다.
