# 북케터 밈 책 소개 카피 예시집

> 실제 @bookketer_mim 에 올린 카드뉴스와, 담당자가 확정한 문안만 모았습니다.
> 기획 AI 는 책추천 3권·5권을 만들 때마다 이 파일을 읽고 **같은 문장 구조와 말투로** 책 장 소개(lines)와 캡션을 씁니다.
> 잘 된 게시물이 생기면 아래에 그대로 덧붙여 주세요(맨 위 규칙은 건드리지 않아도 됩니다).

## 1. 카드(책 장)에 들어가는 소개 — 문장 구조

- 3~5줄, 한 줄이 카드에서 한 줄이 된다(줄당 18~30자, 더 길면 두 줄로 나눈다). 줄마다 "~요." "~요?" "~더라구요." 로 끝나는 말하듯한 문체.
- **흐름: 설정(누가·어떤 상황) → 사건 → "근데" 반전/궁금증 → 여운 한 줄.** 결말은 절대 말하지 않는다.
- 가치 입증(판매량·수상)은 맨 끝 한 줄 이하로만. 먼저 "어떤 내용이고 뭐가 재밌는지"를 보여준다.
- 연두 강조 `[[ ]]`는 훅이 되는 1~2줄(첫 줄 상황 훅이나 "근데" 줄)에만. 한 장에 두 곳 이하.
- 큰따옴표 인용은 원문 그대로일 때만. 확인 못 하면 따옴표 없이 풀어 쓴다.
- "매번·전부·항상" 같은 단정은 쓰지 않는다("대부분"으로).
- 해시태그(카드 흰 박스)는 2~3개: 장르 + 결(분위기) + 화제성/수식어. 예) `#좀비물 #스릴러 #쇼트시리즈1위`

```

강풍에도 쓰러지지 않는다 — 모옌 · `#노벨문학상 #에세이 #위로 힐링`
```
어릴 때 배고파서 개처럼 짖어야 했던 소년
그 소년이 자라서 노벨문학상을 받게되는 실화 이야기
[[할아버지의 일기장을 훔쳐보듯]]
[[웃기다가도 갑자기 훅 뭉클해져요.]]
```

### 담당자가 확정한 카드 문안 (줄거리 훅형 — 소설·스릴러)

빵충 사육 준수 사항 — 김혜영 · `#크리처물 #장르전환 #서울국제도서전화제작`
```

### 성격 진단형 (주제가 "이 책 좋아하는 사람은 ~" 일 때)

어린왕자 — 생텍쥐페리 · `#고전 #순수함 #본질을보는눈`
```
"중요한 건 눈에 보이지 않아"라는 문장으로 유명한 책이에요.
이 책을 좋아하는 당신은 겉모습이나 스펙보다
그 사람 자체를 봐주는, 순수함을 잃지 않은 사람입니다.
```

불편한 편의점 — 김호연 · `#힐링소설 #밀리언셀러 #선입견없는사람`
```
말투도 어눌하고 행색도 허름한 노숙자가 편의점 직원으로 일하면서, 주변 사람들을 하나씩 변화시키는 이야기예요.
이 책을 좋아하는 당신은 첫인상만으로 사람을 판단하지 않고
누구에게나 기회를 주는, 마음이 넓은 사람입니다.
```

## 2. 캡션 — 책 한 권 항목 (카드보다 짧게 2~3줄)

캡션의 책 항목은 카드 문안을 2~3줄로 줄인 것이다. 해시태그는 넣지 않는다.

줄거리 훅형(실제 게시 캡션):
```
1️⃣ 괴물, 용혜 — 김진영
평범하게 살던 용혜에게 어느 날 이상한 일들이 벌어지기 시작해요.
근데 그게 용혜 본인도 모르는 사이 자기가 벌인 일이라면요?
내려야 할 역인데 못 내리게 만드는 몰입감이에요.
```

개인 감상형(실제 게시 캡션 — 심리학·인문·자기계발에 잘 맞음):
```
2️⃣ 칼 융의 내면수업 — 강이안
매번 다른 얼굴로 사는 게 지친다고 느낀 날 읽었는데,
'가면도 나의 일부'라는 말에 마음이 편해졌어요.
```

처방 순서형(썸네일이 "언니ㅠ 헤어졌는데…" 같은 상담형일 때):
```
《좋은 이별》 — 김형경
소설가 김형경의 심리 에세이예요. '잘 이별하는 법'을 정면으로 다루는데, 국내 이별 극복 책 중 가장 오래 스테디셀러 자리를 지키고 있어요.
→ 너 일단 이거부터 읽어
```

캡션 전체 틀(실제 게시):
```
출퇴근길, 지하철이나 기차에서 시간삭제 가능한 책 top5

전부 1시간 완독 가능한 책인데, 안에 담긴 밀도는 절대 안 얇아요 🫶🏻

1️⃣ …(책 항목)…

📌 이번 역 놓칠 각오, 되셨나요 🤍
```

## 3. 스타일 고르기 (사용자가 '자동'으로 두었을 때)

- 소설·스릴러·SF·호러 → 줄거리 훅형(위 1장 구조). 카드 = 설정 → 근데 → 여운.
- 심리학·인문·자기계발·에세이 → 카드는 "이런 순간/이런 사람에게" 공감 훅 + 책이 하는 말 + 그래서 달라지는 것, 캡션은 개인 감상형.
- 주제가 성격·취향 진단이면 성격 진단형, 상담·처방형 썸네일이면 처방 순서형.
