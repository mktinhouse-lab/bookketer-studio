# 롱폼 카드뉴스 지침 (썸네일 + 본문 4~7장 + 마지막 장)

> 이 파일은 기획 AI가 매번 읽습니다. 잘 된 게시물에서 배운 공식을 계속 덧붙여 주세요.

## 흐름 (북케터 밈 기본 뼈대)
1. **썸네일**: 사진 + 연두 라벨 + 흰 헤드라인. 숫자·반전으로 넘기게 만든다.
2. **진짜야? (paper_title)**: 썸네일 주장을 큰 타이포로 다시 확인. 핵심 숫자에 [[형광]].
3. **배경 (photo_box)**: 왜 했는지 / 어떤 일이 있었는지. 핵심 문장 하나에 __물결 밑줄__.
4. **현장·증거 (photo_box 또는 paper_title)**: 숫자, 후기, 반응. 사실만.
5. **방법 (paper_box + bullets)**: "📌 참여 방법, 딱 3단계" 같은 체크리스트.
6. (선택) **주의사항·FAQ (paper_box)**
7. **마지막 장 (dark_cta)**: "북케터밈을 팔로우하고, [[댓글]] 달면 ○○ 보내드릴게요!"

## 템플릿 쓰는 법
- `paper_title`: label = 작은 눈썹 문구, headline = 2~4줄 큰 문장, body = 1~2줄 보조.
- `photo_box`: label = 굵은 제목 박스(15자 안팎), body = 3~5줄. bullets 없이.
- `paper_box`: label = "📌 제목", bullets 3개 이내(각 16자 안팎), body 는 비우거나 한 줄.
- 한 장에 강조는 1~2곳. 본문 한 줄은 20자 안팎에서 끊는다(\n).

## 썸네일 훅 공식
- 숫자 충격형 / 반전 판결형 / 호명형 / 현장 증언형 / 조건 혜택형 (single.md 참고)
- 롱폼은 썸네일에서 결론을 다 말하지 않는다. "생긴 일", "이유", "방법"처럼 넘겨야 알 수 있게 남긴다.

## 통과 기준
1. 2장만 봐도 무슨 이야기인지 안다.
2. 장마다 하나의 메시지만 있다.
3. 사실·숫자는 사용자가 준 것만.
4. 마지막 장 CTA와 캡션 CTA가 같은 행동을 요구한다.
5. 저장할 이유(방법·목록·지도)가 하나 이상 있다.
