# 단일 카드뉴스 지침 (썸네일 + 마지막 장, 2장)

> 이 파일은 기획 AI가 매번 읽습니다. 잘 된 게시물에서 배운 공식을 계속 덧붙여 주세요.

## 구성
1. 썸네일 한 장으로 끝까지 읽히게 한다. 사진 + 연두 라벨 + 흰 헤드라인 2~3줄.
2. 마지막 장(dark_cta)은 팔로우·댓글·저장 중 하나만 분명하게 요구한다.
3. 이야기는 캡션이 맡는다. 썸네일은 호기심, 캡션은 사연과 정보.

## 썸네일 훅 공식 (하나를 골라 후보마다 다르게)
- **숫자 충격형**: [큰 숫자] + [의외의 행동] → "서점 10곳에 [[1000만 원]] 뿌렸더니"
- **반전 판결형**: [흔한 오해] + [뒤집는 결론] → "책 안 읽는 게 아니라, [[고를 시간]]이 없던 거야"
- **호명형**: [자칭할 수 있는 라벨] + [보상] → "책 사놓고 안 읽는 사람, 이건 [[꼭 와]]"
- **현장 증언형**: [직접 본 장면] + [감탄] → "서점에 [[줄 선 거]], 살면서 처음 봤어요"
- **조건 혜택형**: [간단한 조건] + [공짜·선물] → "댓글만 달면 [[책 한 권]] 보내줄게"

## 통과 기준 (후보마다 스스로 점검)
1. 첫 줄만 읽어도 누구 얘기인지 알 수 있다.
2. 숫자나 반전이 하나 이상 있다.
3. 사용자가 준 사실과 어긋나지 않는다.
4. 사진 가이드가 카피의 감정과 같은 방향이다(설레는 카피 + 웃는 얼굴).
5. 공유·태그할 명분이 있다("친구 태그해서 같이 가자").

## 캡션 구조
```
첫 줄: 썸네일 카피를 문장으로 (훅)
· · ·
⠀
상황 2~3줄 (왜 이걸 했는지 / 무엇이 일어났는지)
⠀
핵심 정보 (날짜·장소·방법) — 사실만
⠀
참여 방법 / CTA 한 줄
⠀
고정 문구(프로젝트에 적어 둔 것)
⠀
#해시태그 8~15개
```
- 빈 줄 대신 `⠀`(점자 공백)으로 문단을 띄운다.

## 고정댓글
- 3~6줄. 캡션 요약 한 줄 + 행동 요청 + 링크/프로필 안내.
