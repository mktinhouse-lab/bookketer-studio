# 책추천 3권 지침

> 기준 게시물: https://www.instagram.com/p/DdTX_rUH0wZ/ (원래 5권 → 3권으로 줄인 형식)
> 이 파일은 기획 AI가 매번 읽습니다. 잘 된 게시물에서 배운 걸 계속 덧붙여 주세요.

## 구성 (5장)
1. **표지**: 사진 + 왼쪽 위 흰 라벨 2개(북케터 밈 / 책 추천) + 아래 큰 헤드라인 2줄
   - 1줄: 짧은 훅(빨강 강조 `{{ }}`) 예) `{{1시간 완독}}`
   - 2줄: 리스트 제목(흰색) 예) `얇지만 도파민 미친 책 3`
2~4. **책 한 장씩**: 연두 책 제목 박스 → 흰 해시태그 박스(#3개) → 책 표지 → 소개 3~4줄
   - 소개 1줄: 상황·설정(가장 궁금해지는 장면) — `[[ ]]` 연두 강조
   - 소개 2~3줄: 전개·반전·설정
   - 소개 마지막 줄: 이 책을 읽어야 하는 이유(수상·판매 1위·몰입감 등 사실만)
   - 한 줄 22자 안팎, 스포일러는 "(반전주의)"로 끊는다
5. **팔로우 장**: "북케터밈을 팔로우하고," / "분야별 추천 도서를 빠르게 챙겨가세요!"

## 표지 헤드라인 공식
- 시간·상황 + 효용: `{{1시간 완독}}` / 얇지만 도파민 미친 책 3
- 대상 호명: 20대라면 / 꼭 읽어봐야 하는 심리학 책 3
- 장소·순간: 출퇴근길 / 시간 삭제되는 소설 3

## 캡션 구조
```
훅 한 줄 (예: 출퇴근길, 시간삭제 가능한 책 top3)
⠀
한 줄 소개 + 🫶🏻
⠀
1️⃣ 책 제목 — 저자
설정 한 줄
전개 한 줄
읽어야 하는 이유 한 줄
⠀
2️⃣ …
⠀
📌 저장 유도 한 줄
```
- 책 소개 문안은 사용자가 쓰지 않는다. AI가 책마다 서점 책소개·줄거리를 웹 검색으로 확인하고, book_copy_examples.md(실제 게시 카드·캡션 예시집)와 같은 구조·말투로 쓴다. 확인 안 된 정보는 쓰지 않는다.

- 캡션에는 해시태그를 넣지 않는다(키워드 #은 카드에만). 자세한 카피 규칙은 book_rules.md.
