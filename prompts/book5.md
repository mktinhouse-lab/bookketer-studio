# 책추천 5권 지침

> 기준 게시물: https://www.instagram.com/p/DcQZE1DGeLA/
> 이 파일은 기획 AI가 매번 읽습니다. 잘 된 게시물에서 배운 걸 계속 덧붙여 주세요.

## 구성 (7장)
1. **표지**: 인물 사진(책 표지 콜라주가 어울림) + 왼쪽 위 흰 라벨 2개(북케터 밈 / 책 추천) + 아래 흰 헤드라인 2줄
   - 예) `20대라면` / `꼭 읽어봐야 하는 심리학 책 5`
   - 강조가 필요하면 1줄에 `{{빨강}}` 또는 `[[연두]]`
2~6. **책 한 장씩**: 연두 책 제목 박스 → 흰 해시태그 박스(#3개) → 책 표지 → 소개 4~5줄
   - 1줄: 이런 사람·이런 순간에 필요한 책 (`[[ ]]` 연두 강조)
   - 2~3줄: 책이 어떤 이야기·내용인지
   - 4~5줄: 그래서 무엇이 달라지는지 (`[[ ]]` 연두 강조)
   - 말투는 친구에게 추천하듯 "~더라구요", "~예요"
7. **팔로우 장**: "북케터밈을 팔로우하고," / "분야별 추천 도서를 빠르게 챙겨가세요!"

## 캡션 구조
```
📚 리스트 제목 (예: 20대라면 꼭 읽어봐야 하는 심리학·인문 책 5권)
⠀
왜 추천하는지 한두 줄 + 🫶🏻
⠀
1️⃣ 책 제목 — 저자
내가 어떤 시기에 읽었는지 / 어떤 문장이 남았는지 2줄
⠀
… 5️⃣ 까지
⠀
📌 저장 유도 한 줄 🤍
```
- 책 소개 문안은 사용자가 쓰지 않는다. AI가 책마다 서점 책소개·줄거리를 웹 검색으로 확인하고, book_copy_examples.md(실제 게시 카드·캡션 예시집)와 같은 구조·말투로 쓴다. 확인 안 된 정보는 쓰지 않는다.

- 캡션에는 해시태그를 넣지 않는다(키워드 #은 카드에만). 자세한 카피 규칙은 book_rules.md.
