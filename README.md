# 북케터 밈 카드뉴스 스튜디오

회사의 **북타쿠 카드뉴스 스튜디오** 구조(레퍼런스 → 기획 후보 3개 → 썸네일 편집 → 저장)를 북케터 밈 형식으로 새로 만든 로컬 프로그램입니다.

## 실행
`run.bat` 더블클릭 → 브라우저에서 http://127.0.0.1:8765 이 열립니다. 검은 창이 서버이고, 닫으면 꺼집니다.

## 처음 한 번만
1. **Claude 로그인**: 1번 칸의 `Claude 로그인 창 열기` → 구독 계정(Pro/Max)으로 로그인. API 키 없이 구독 요금제로 돌아갑니다.
2. **인스타 로그인**: 2번 칸의 `로그인 세션 저장` → 열린 창에서 로그인(수집 전용 부계정 권장). 세션은 `data/.session/`에 저장됩니다.

## 형식 (1번 칸에서 버튼으로 선택)
| 형식 | 구성 | 기준 게시물 |
|---|---|---|
| 책추천 3권 | 표지(라벨 상자 + 빨강/흰 헤드라인) → 책 3장 → 팔로우 장 | instagram.com/p/DdTX_rUH0wZ (5권 → 3권) |
| 책추천 5권 | 표지 → 책 5장 → 팔로우 장 | instagram.com/p/DcQZE1DGeLA |
| 30초 요약 | 표지 → 목차 → 키워드 2개씩 → 셀프체크 → 팔로우 장 | instagram.com/p/DebTFiHnwsf |
| 자유 롱폼 / 단일 | 레퍼런스 공식대로 | — |

- 책추천: '추천할 책 목록'에 `제목 / 저자 / 메모`를 한 줄에 한 권씩 적으면 됩니다. 책 표지는 교보문고·알라딘에서 자동으로 찾아요(못 찾으면 카드 편집에서 올리기).
- 30초 요약: 책 제목·저자·키워드 개수를 넣고 내용은 '사실 정보' 칸에 붙여 넣으세요. **키워드 요약**(트렌드·개념서)과 **자기계발 핵심 요약** 중에서 고릅니다. 키워드마다 배경 사진은 핀터레스트에서 자동으로 찾아요.
- 책 장·목차 장 배경 사진과 팔로우 장 프로필 사진은 1번 칸에서 한 번 올려 두면 계속 씁니다(`assets/book_bg.jpg`, `assets/profile.jpg`).
- 형식 지침: `prompts/book3.md`, `prompts/book5.md`, `prompts/summary.md`
- 북케터 밈 형식은 레퍼런스 없이 **[이 형식으로 바로 기획하기]**로도 만들 수 있고, 2번에서 레퍼런스를 고르면 그 훅도 참고합니다.

## 작업 지침에서 가져온 기능
- **AI로 책 찾기** (책추천 형식): 썸네일 카피나 장르를 적으면 AI가 웹에서 후보를 찾고, 교보문고에서 실존·저자·절판·평점을 확인해 보여 줍니다. 체크한 책이 '추천할 책 목록'에 들어갑니다. 기록: `analysis/…_책찾기_….md`
- **책 소개 문안 자동 작성**: 책추천 3권·5권은 책 소개(카드 3~5줄 + 캡션 2~3줄)를 직접 쓰지 않아도 됩니다. AI가 책마다 서점 책소개를 웹 검색으로 확인하고, `prompts/book_copy_examples.md`(실제 게시 카드·확정 문안 예시집)와 같은 구조·말투로 씁니다. 잘 된 게시물이 생기면 이 파일에 덧붙이세요.
- **카피 스타일**: 자동(기존 게시물처럼) / 줄거리 훅 / 개인 감상 / 성격 진단 / 처방 순서 중에서 고릅니다. 규칙은 `prompts/book_rules.md`에 있습니다.
- **링크로 가져오기 (로그인 필요 없음)**: 찾아 둔 레퍼런스 링크를 넣으면 공개 임베드 페이지에서 사진·캡션·좋아요를 가져옵니다. [바로 기획]에 체크하면 가져오자마자 기획을 시작합니다.
- **카피 베리에이션**: 레퍼런스 카드의 [카피 베리에이션]을 누르면 원본 카피, 공식, 변형 8개와 추천을 보여 줍니다. [이 카피로]를 누르면 썸네일 카피 칸에 들어갑니다. 기록: `analysis/…_카피베리에이션_….md`
- **팩트체크**: 책추천 후보의 [팩트체크]를 누르면 교보문고와 웹 검색으로 제목, 저자, 줄거리, 인용을 확인합니다. 고친 후보는 새 라운드로 저장됩니다.

## 흐름
1. **알릴 내용 · 형식**: 주제, 핵심 메시지, 사실 정보, CTA, 캡션 끝 고정 문구를 적고 `프로젝트 저장`. 형식은 단일(2장)·롱폼(썸네일 + 본문 + 마지막 장).
2. **레퍼런스 수집**
   - 방법 A: 인스타 검색창 키워드로 스크롤하며 찾고, 게시물마다 인스타 웹 API로 좋아요·댓글·슬라이드를 정확히 읽습니다. 최소 좋아요(기본 5,000), 최근 N일, 형식 조건을 통과한 것만 최대 10개 모읍니다. 상위 댓글도 함께 모읍니다.
   - `새로 찾기`: 전에 살펴본 게시물은 빼고 더 아래까지 찾습니다.
   - 방법 B: 게시물 링크를 붙여넣어 수집합니다.
   - 카드를 눌러 레퍼런스를 1~3개 고른 뒤 `선택한 레퍼런스로 기획하기`.
3. **작업대 · 기획**: AI가 레퍼런스 이미지·캡션·댓글 반응을 보고 후보 3개를 만듭니다. 후보마다 썸네일 카피, 라벨, 말풍선, 공식, 공유 명분, 본문 장, 마지막 장, 캡션, 고정댓글이 들어 있습니다. 핀터레스트에서 배경 후보를 찾아 AI가 순위를 매깁니다. 피드백을 적으면 전체 또는 특정 후보 기준으로 다시 기획하고, 라운드가 쌓입니다.
4. **캔버스 편집**: 후보를 고르면 썸네일 편집기가 열립니다. 배경 교체, 이미지 더 찾기(방향 지정 가능), 어둡게 깔기, 글자·라벨·말풍선 편집이 가능하고, `[[단어]]`는 연두 강조입니다. 저장하면 나머지 장까지 한 번에 만들어집니다.
5. **완성본**: 장마다 편집, 내 이미지로 바꾸기, 순서 바꾸기, 빼기, 이미지 장 추가를 할 수 있습니다. 캡션과 고정댓글을 고치고, zip으로 내려받을 수 있습니다. 바탕화면 › 카드뉴스 완성본 › 오늘 날짜 폴더에 자동 저장됩니다.
6. **작업 보관함**: 모든 기획 후보(안 쓴 후보 / 저장됨)를 모아 보여 줍니다. 다시 편집하거나 고칠 수 있습니다.
7. **결과 보기**: 수집 → 기획 → 생성 md 기록을 3칸 보드로 보여 줍니다. 누르면 이어진 기록이 함께 표시되고, md 원문과 이미지를 볼 수 있습니다. 선택해서 휴지통으로 옮길 수도 있습니다.

## 저장 위치 (`data/`)
| 폴더 | 내용 |
|---|---|
| `crawl/` | `20261013-142137_검색_책추천.md` + `_assets/`(슬라이드 이미지) |
| `analysis/` | 기획 md (라운드·후보 3개·캡션·고정댓글) |
| `generate/` | 이미지 후보 md(+`_assets`), 썸네일 편집본 md, 완성본 md(+`_cards`) |
| `휴지통/` | 결과 보기에서 지운 기록 |
| `.session/` | 인스타 로그인 세션 (외부 공유 금지) |

- 파일 이름은 초 단위 시각으로 시작하고, 같은 이름이 있으면 `_2`, `_3`을 붙여 덮어쓰지 않습니다.
- md 끝 `원본 데이터` 블록에 화면이 쓰는 데이터가 함께 들어 있습니다. md 파일만 있으면 다시 열 수 있습니다.

## 고치고 싶을 때
- 말투·디자인 규칙: `brand_guide.md`
- 카피 공식·캡션 구조: `prompts/single.md`, `prompts/long.md`. 잘 된 게시물에서 배운 걸 계속 덧붙이세요.
- 마지막 장을 고정 이미지로 쓰려면 `assets/cta.png`(1080×1350)를 넣으세요.
- 썸네일 틀: `static/app.js`의 `T`(크기·색·위치), 본문 장 틀: `app/render.py`의 CSS
- 모델: 환경변수 `BOOKKETER_MODEL` (기본 `claude-opus-5-5`)
